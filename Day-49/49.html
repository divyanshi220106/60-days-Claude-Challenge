What is this?

This is a personal AI Playbook — a library of reusable prompt systems for coding work, built around your bottleneck: AI code that's almost right but needs fixing.

The four sections
  • Dashboard — ready-made workflows, grouped by what they're for. Fill in variables, copy, done.
  • Prompt Builder — assemble a prompt from labeled parts instead of writing one from scratch each time.
  • Loop Builder — wrap a prompt in self-checking criteria so the AI verifies its own output.
  • My Workflows — everything you save, searchable and favoritable, stored on this device.
Good to know

Everything here is stored in your browser's local storage — nothing leaves this device. Use Export to back up your library as a JSON file.
