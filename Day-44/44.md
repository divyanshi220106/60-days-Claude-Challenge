# Day 44 — AI LinkedIn Profile Optimizer

## 🎯 Objective
Build an interactive AI-powered tool that roasts, rebuilds, and scores a LinkedIn profile — then generates a personalized 7-day activation plan — using the Anthropic API directly inside a single HTML application ("Claude in Claude").

## 🛠️ Tool Used
- **Claude (Anthropic)** — used both to design the tool and to power it live via the `/v1/messages` API endpoint called directly from the HTML file (`claude-sonnet-4-6`)
- Single self-contained `.html` file — no backend, no build step, runs in any browser

## ⚙️ How It Works
1. **Intake form** — user chooses "I have a profile" or "I don't have one yet," then fills in headline, About section, most recent experience entry, top skills, and target goal (job/internship, clients, thought leadership, or network growth)
2. On submit, the app sends a structured prompt to the Claude API instructing it to act as an ex-recruiter and LinkedIn optimization expert, and to return **strict JSON only** — no invented achievements, metrics, or companies
3. The JSON response is parsed client-side and rendered into 5 tabs:
   - **Roast** — section-by-section scores (Headline, About hook, About full, Experience, Skills) with a recruiter's real reaction
   - **Rebuild** — 3 headline options, a full About rewrite, an Experience bullet rewrite (or a fill-in-the-blank template if no bullets existed), and skills to add/remove/pin
   - **Scorecard** — Before vs After per section
   - **7-Day Plan** — daily checklist, post drafts, connection message templates, the "Agree + Insight + Question" value-comment formula
   - **Summary Card** — a screenshot-ready before/after card for sharing

## ✅ Key Learnings
1. **AI is most useful when it's constrained, not just capable.** The biggest engineering decision wasn't the UI — it was writing a system prompt that explicitly forbids fabricating achievements/metrics and instead returns bracketed placeholders when information is missing.
2. **Structured JSON output turns an LLM into a UI data source.** By forcing the model to return a fixed schema, the same HTML/CSS shell can render *any* person's profile audit without rebuilding the interface each time.
3. **A profile's weakest section is usually the "boring" one.** In testing, empty Experience descriptions consistently scored as the single highest-impact fix — lower than a messy headline or a generic About paragraph.
4. **Calling the Anthropic API from inside an artifact ("Claude in Claude")** is a genuinely different pattern from asking Claude for one-off advice — it turns a static conversation into a reusable, personalized tool anyone can run with their own inputs.
5. **Good prompting is inseparable from good product design.** Deciding what happens when a field is left blank, how scores should be capped when a rewrite is only a template, and how to keep the tone "honest, not harsh" all had to be specified in the prompt itself.
