# 🚗 Day 17 – Vehicle Cost Analysis Dashboard

## Overview

For Day 17 of the #60DaysOfClaudeChallenge, I built a Vehicle Cost Analysis Dashboard using Claude AI, HTML, CSS, JavaScript, and SVG-based visualizations.

The dashboard transforms vehicle fuel and maintenance data into actionable insights, helping users compare running costs, environmental impact, and fuel efficiency across different fuel types.

## Key Insights

### E85 Economics

The dashboard demonstrates that lower pump prices do not automatically result in lower running costs.

Important factors include:

* Mileage
* Fuel Efficiency
* Maintenance Cost
* Refueling Time
* Environmental Impact

### Vehicle Ownership Economics

True ownership cost depends on:

1. Fuel Cost
2. Maintenance Cost
3. Vehicle Age
4. Carbon Footprint
5. Operational Efficiency
