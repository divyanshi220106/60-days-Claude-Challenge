# Day 16 – Claude Custom Skill: Stock Fundamental Research

## Overview

Today, I created a reusable Custom Skill in Claude called **stock-fundamental-research** that performs evidence-based fundamental analysis of Indian and global listed companies.

The skill analyzes financial statements, valuation metrics, ownership patterns, business quality, risks, competitive advantages, and growth prospects while avoiding investment advice or stock recommendations.

---

## Skill Details

### Skill Name

`stock-fundamental-research`

### Description

Analyze Indian and global listed companies using fundamentals, financial statements, business quality, competitive advantages, valuation, risks, and growth prospects. Generate evidence-based research reports and investor-friendly summaries. Never provide direct buy, sell, or hold recommendations.

## Workflow

1. Open Claude
2. Navigate to Skills
3. Create a New Custom Skill
4. Add Skill Name and Description
5. Paste Instructions
6. Save the Skill
7. Test using stocks such as:

   * TCS
   * Infosys
   * Reliance Industries
   * HDFC Bank
   * Tata Motors
8. Generate reports and compare companies
9. Review valuation, ownership, growth, and risk factors
