# Day 45 — AI Decision Strategist

## What I Built
An interactive HTML "Decision Report" generator using Claude. I fed Claude a structured system prompt that turned it into an impartial Decision Strategist — it interviews the user with 4 focused questions, then generates a full single-file interactive dashboard analyzing the decision.

## The Example Decision
**Stay at current job (₹8L/year, stable) vs. join a startup (₹11L/year, high growth, but only 12 months of confirmed funding).**

## What the Tool Generated
- **The Real Decision** — a plain-language framing of the actual trade-off
- **Case For Each Option** — strengths, hidden upsides, weaknesses, and "best if you value" tags for both paths
- **Assumption Buster** — called out loss aversion and status quo bias, and flagged an unexamined option (negotiating a safety net before committing)
- **Decision Matrix** — 7-dimension scoring (career upside, financial safety, growth, stress, reversibility, alignment, regret risk) with animated bars, totals: Stay 46/70 vs Startup 42/70
- **Premortem** — 12-months-later failure scenarios for both options, each with an early warning sign and a prevention action
- **7-Day Test Plan** — concrete research → experiment → conversation → decision-day criteria
- **The Verdict** — a decisive call ("stay for now, build the safety net, then take the risk") with a stated condition that could flip it
- **Shareable Cards** — 3 screenshot-ready mini cards (matrix summary, verdict, LinkedIn-style hook)

## Key Learnings
1. **Structured interviews beat open-ended prompts.** Locking Claude to exactly 4 short questions (with no analysis until the end) kept the interaction fast and free-tier friendly, while still gathering enough signal for a decisive verdict.
2. **A decision matrix forces honesty.** Scoring both options on the same 7 dimensions surfaced the real trade-off (financial safety vs. growth speed) instead of a vague "just go with your gut."
3. **Premortems are more useful than pros/cons lists.** Imagining failure for *both* options — not just the risky one — revealed that "staying" has its own failure mode (stagnation), which is easy to ignore.
4. **A single self-contained HTML file is a great deliverable format.** No build step, no dependencies beyond a Google Fonts import — just open it in a browser. Good for portfolio/GitHub submissions.
5. **Design specs matter as much as content specs.** Giving Claude exact CSS variables, spacing, and animation rules produced a consistent dark-mode dashboard instead of a generic layout.
