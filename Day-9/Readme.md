# Day 9 – NutriScope: AI-Powered Nutrition Tracker

## Overview

Day 9 focused on building and enhancing **NutriScope**, a nutrition tracking and recommendation application using AI-assisted development.

The objective was to compare how AI can generate an MVP version of an application and then enhance it with advanced features through iterative prompting.

---

## Project Workflow

### Step 1: MVP Development

Generated the initial version of NutriScope using Claude AI.

Features included:

* User Profile Management

  * Age
  * Gender
  * Height
  * Weight
  * Activity Level
  * Dietary Preference

* Food Logging System

  * Add Food
  * Quantity Tracking
  * Unit Selection
  * Remove Entries

* Food Database

  * 20 Common Foods

* Nutrient Tracking

  * Calories
  * Protein
  * Carbohydrates
  * Fat
  * Fiber
  * Iron
  * Calcium
  * Vitamin C
  * Vitamin D
  * Vitamin B12

* Dashboard

  * Energy Summary
  * Macronutrient Tracking
  * Nutrient Deficiency Detection
  * Recommendations

* Responsive Dark Theme UI

---

## Step 2: Enhanced Version

Using a second prompt, the application was upgraded with additional features.

Enhancements included:

* CSV Upload Support
* Expanded Food Database (+40 Foods)
* Additional Micronutrients
* Advanced Analytics
* Risk Analysis
* Two-Day Meal Planner
* Educational Disclaimer
* Nutrition Source References
* Improved Charts
* Advanced Recommendations Engine

## Key Learnings

* AI can rapidly generate functional MVPs.
* Iterative prompting significantly improves application quality.
* Prompt engineering directly impacts feature completeness.
* Comparing versions helps evaluate AI-generated improvements.
* Frontend applications can be built quickly without backend infrastructure.

---

## Challenges Faced

* Understanding prompt requirements.
* Comparing generated outputs objectively.
* Evaluating feature enhancements.
* Managing AI usage limits during development.

---

## Outcome

Successfully created and compared two versions of NutriScope:

1. MVP Version
2. Enhanced Version

This exercise demonstrated how structured prompting can transform a simple application into a significantly more capable solution.
