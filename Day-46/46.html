Architecture Overview

Planner

Reads the campaign brief and produces a per-platform content strategy: hook angle, tone calibration, and key message hierarchy for Instagram, Facebook, and LinkedIn.

Executor

Writes the first full draft ad set from the Planner's strategy — one variant per platform, matched to each platform's format conventions.

Evaluator

Scores the current draft 0–10 against a persuasiveness / clarity / brand-fit rubric every single round, with written reasoning. This is the only source of the score shown in the UI.

Critic

Given the Evaluator's report, identifies concrete weaknesses per platform — weak hooks, vague CTAs, tone drift — that the Improver must act on.

Improver

Rewrites the draft addressing the Critic's notes and the Evaluator's reasoning, receiving the full prior-round context each time it's called.

Memory Manager

Condenses each round into a running memory log of what changed and why, threaded into every subsequent Improver and Evaluator call so the loop doesn't repeat past mistakes.

Safety Monitor

Flags unsubstantiated claims, platform-policy risk, or misleading language in the current draft each round — advisory, surfaced in the dashboard, doesn't block the loop.

Final Reviewer

Runs once, after a stop condition fires, doing a last polish pass and QA sign-off on the winning draft before it's presented as final output.

Extension Ideas

Multi-variant A/B branching

Run the Executor twice per platform and let the Evaluator pick a winner before entering the improvement loop.

Human-in-the-loop checkpoints

Pause after any round for a person to approve, edit, or redirect the Critic's next pass instead of always auto-continuing.

Persistent brand memory

Let the Memory Manager write to long-term storage so future campaigns start from what worked for this brand before.

Tool-using agents

Give the Planner web search access for competitor ad research, or the Safety Monitor a real policy-lookup tool per platform.

Further Prompts For Building More Advanced Autonomous Systems

• "Add a human-approval gate before Final Reviewer that pauses the loop and asks for explicit sign-off."

• "Extend the Evaluator to run three independent scoring passes per round and average them, to reduce single-call variance."

• "Add a Router agent upfront that decides which of the 8 agents are actually needed for a given brief, instead of always running all eight."

• "Persist iteration history to local storage so a session can be resumed after a page reload."

• "Add a cost/latency tracker agent that reports total tokens and time spent per round in the dashboard."
