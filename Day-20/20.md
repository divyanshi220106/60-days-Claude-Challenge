# Day 20 – Face Puzzle Game

## Overview

Today, I built a Face Puzzle Game using HTML, CSS, and JavaScript as part of the #60DaysOfClaudeChallenge.

The application allows users to capture their face using the webcam and convert it into an interactive puzzle. Users can select different difficulty levels and solve the puzzle while tracking time and moves.

---

## Features Implemented

### Camera Integration

* Webcam access using getUserMedia()
* Live camera preview
* Face photo capture
* Retake photo option

### Puzzle Generation

* Difficulty Levels:

  * 3×3
  * 4×4
  * 5×5
* Dynamic puzzle creation from captured image
* Random puzzle shuffling

### Game Mechanics

* Drag and Drop puzzle pieces
* Touch support for mobile devices
* Move counter
* Live timer
* Correct piece tracking

### Results & Leaderboard

* Automatic win detection
* Results popup
* Best scores saved using LocalStorage
* Leaderboard displaying top performances

### UI & UX

* Dark modern interface
* Responsive design
* Mobile-friendly layout
* Interactive controls and animations
