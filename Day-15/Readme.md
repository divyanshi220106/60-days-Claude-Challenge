# Day 15 – AI Astrology & Life Analysis Assistant

## Objective

Build an AI-powered astrology assistant capable of collecting personal birth information and generating a detailed life analysis report.

---

## Prompt Used

You are an expert Vedic astrologer specializing in Parashara, Jaimini, Nakshatra, Vimshottari Dasha, and Transit Analysis.

Before starting, collect:

* Full Name
* Gender
* Date of Birth
* Exact Birth Time
* Birth Time Accuracy
* Place of Birth
* Current City
* Relationship Status
* Profession
* Top 3 Current Concerns

Generate:

1. Birth Chart Summary
2. Life Pattern Analysis
3. Career & Wealth Analysis
4. Relationship & Marriage Analysis
5. Current Dasha Analysis
6. 5-Year Forecast
7. Remedies

Use tables wherever possible and explain reasoning behind conclusions.

---

## Workflow

1. Open Claude
2. Set effort level to Low or Medium
3. Start a new chat
4. Paste the astrology prompt
5. Provide required personal details
6. Generate complete report
7. Review findings
8. Save screenshots
9. Upload outputs to GitHub

---

## Key Learnings

* Complex prompt structuring
* Multi-step information collection
* Long-form report generation
* AI reasoning and analysis workflows
* User-centric report design
