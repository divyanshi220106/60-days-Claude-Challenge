# 🚀 Day 26 – Prior Authorization Workflow Simulator

## 📌 Project Overview

Today I built an **Interactive Prior Authorization Workflow Simulator** using **HTML, CSS, and Vanilla JavaScript**. The project gamifies the US Healthcare Prior Authorization (PA) process, allowing users to understand how patient requests move through different stakeholders.

The simulator demonstrates the complete workflow from **Patient → Provider → Payer**, making a complex healthcare process easier to understand.

---

# ✨ Features

* 🎯 Interactive Prior Authorization workflow
* 🏥 Three workflow lanes

  * Patient
  * Provider / Clinic
  * Payer / Insurance
* 🩺 Medical Necessity Evaluation
* 📄 Required Document Collection
* 📤 PA Submission Process
* ⚖️ Review Outcomes

  * Approval
  * Pend
  * Denial
  * Appeal
  * Peer-to-Peer Review
* 📈 Workflow Progress Tracker
* 📅 Days Elapsed Counter
* ⚡ Efficiency Score
* 🎉 Approval Celebration Animation
* 📊 Workflow Summary Dashboard
* 🔄 New Patient / Restart Workflow
* 📱 Fully Responsive UI
