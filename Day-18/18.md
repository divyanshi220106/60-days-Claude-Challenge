# 🧠 Day 18 – Brain Dump Action Planner

## Overview

For Day 18 of the #60DaysOfClaudeChallenge, I created a powerful Claude Custom Skill called **Brain Dump Action Planner**.

The skill transforms messy notes, meeting transcripts, brainstorming sessions, voice memos, and project discussions into a structured action dashboard.

Instead of manually sorting through pages of information, the skill automatically organizes insights into actionable sections that improve clarity, accountability, and execution.

---

## Problem

Important information is often scattered across:

* Meeting Notes
* Brainstorming Sessions
* Voice Memo Transcripts
* Project Discussions
* Class Notes

Extracting action items and tracking decisions manually can be time-consuming and inefficient.

---

## Solution

The Brain Dump Action Planner converts unstructured information into a modern dashboard containing:

✅ Summary

✅ Key Takeaways

✅ Action Items

✅ Open Questions

✅ Risks & Blockers

✅ Conflicts

✅ Additional Notes

✅ Source Information

---

## Dashboard Preview

The generated dashboard provides:

### Action Tracking

* Task Owner
* Deadlines

* Completion Status

### Decision Visibility

* Open Questions
* Pending Decisions
* Dependencies

### Risk Management

* Blockers
* Project Risks
* Timeline Concerns

### Information Organization

* Structured Summaries
* Key Highlights
* Source References

---

## Features

### Full Breakdown Mode

Transforms raw notes into a structured dashboard.

### Transcript Mode

Provides:

* Speaker Summaries
* Decisions by Speaker
* Action Items by Speaker
* Attribution Notes

### Merge Mode

Supports multiple documents and generates:

* Duplicate Detection
* Conflict Tracking
* Source Mapping
