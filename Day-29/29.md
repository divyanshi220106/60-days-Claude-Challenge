# Day 29 — Operation Lifeline: Supply Chain Crisis Lab 🌐

## Project Overview

A fully interactive, single-file HTML simulation game that puts you in the role of a Supply Chain Director managing a real-world crisis. Built with React (CDN), plain CSS, and JavaScript — no backend, no npm, no internet required.

---

## 🎮 What I Built

**Operation Lifeline: Supply Chain Crisis Lab** is a 7-phase browser-based simulation that teaches supply chain crisis management through hands-on decision making.

### Simulation Phases

| Phase | Description |
|-------|-------------|
| 🏢 Company Profile | Randomly generated fictional company — industry, revenue, factories, suppliers, countries |
| 🚨 Crisis Alert | 1 of 8 disasters: factory fire, cyberattack, flood, port strike, supplier bankruptcy, and more |
| ⚔️ War Room | Choose 3 of 6 response actions — each with real trade-offs on cost, inventory, and satisfaction |
| 🤝 Supplier Negotiation | 4-round branching negotiation affecting Trust, Price, and Lead Time |
| 👔 CEO Boardroom | 5 leadership dilemmas scored on executive decision-making quality |
| 🤖 AI Strategy | Select 2 AI investments from Demand Forecasting, Inventory Optimization, Supplier Risk Monitoring, and more |
| 📊 Final Dashboard | Overall score (0–100) across 6 KPIs + personalized debrief and lessons learned |

---

## 🛠️ Tech Stack

- **React 18** via CDN (no npm)
- **Babel Standalone** for JSX in-browser transpilation
- **Plain CSS** with CSS custom properties (dark theme)
- **Vanilla JavaScript** for all game logic
- **Single HTML file** — runs 100% offline

## 💡 Key Learnings

### Supply Chain Concepts
- **Safety Stock vs. Agility**: Drawing down reserves buys time but creates downstream risk
- **Supplier Trust**: Negotiation outcomes depend as much on relationship quality as price leverage
- **Crisis Communication**: Proactive transparency preserves customer loyalty better than any operational fix
- **AI in Supply Chain**: Demand forecasting and supplier risk monitoring have the highest ROI for disruption prevention
- **Lead Time Reality**: With 30–60 day lead times, decisions made today affect outcomes 6–8 weeks from now

### Technical Learnings
- Building stateful multi-phase apps with React `useState` and CDN delivery
- Designing reusable components (`ProgressBar`, `MetricRow`, `StepNav`, `OptionCard`) for complex game UI
- Implementing randomized game state that produces unique experiences every playthrough
- Creating animated progress bars with CSS transitions and delayed state updates
- Dark enterprise dashboard design using CSS variables and gradient layering

### AI-Assisted Development
- Used Claude to architect the full game flow from a single detailed prompt
- Iterated on component structure, game balance, and UX copy
- Learned how to write precise prompts that produce complete, runnable code

## 📊 Simulation Outcomes Tracked

- **Cost Control** — How well spending was managed during the crisis
- **Inventory Level** — Buffer maintained through the disruption
- **Profit Margin** — Financial health post-crisis
- **Delivery Speed** — Fulfillment performance during the event
- **Customer Satisfaction** — Loyalty and trust preservation
- **Leadership Score** — Quality of executive decision-making
- **Negotiation Score** — Supplier relationship outcome
- **Resilience Score** — Combined inventory + delivery recovery

---

## 🚀 How to Run

1. Download `operation-lifeline.html`
2. Double-click to open in any modern browser
3. Click **Start Simulation**
4. Complete all 7 phases (~10 minutes)
5. Review your Executive Dashboard
6. Click **Replay** for a new scenario

No installation. No internet. No account needed.

---

## 🔁 Replayability

Every playthrough randomizes:
- Company name, industry, revenue, and operational profile
- Active crisis type and business impact
- Supplier negotiation dynamics
- CEO boardroom question scoring
- Final score composition and feedback
