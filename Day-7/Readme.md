# 🚀 Day 7 - My Claude Usage Strategy

## 📌 Challenge Overview

Day 7 of my Claude AI Learning Challenge focused on creating a personalized Claude Usage Strategy.

The goal was to understand:

* Which Claude model fits my workflow best
* When to use Haiku, Sonnet, and Opus
* How effort levels impact output quality
* How to optimize Claude for coding, learning, projects, and career preparation

## ⚡ When to Use Haiku

Use Haiku for:

* Quick answers
* Definitions
* Summaries
* Brainstorming ideas
* Fast responses

### Why?

Haiku is lightweight and optimized for speed.

---

## 🧠 When to Use Sonnet

Use Sonnet for:

* Coding and debugging
* Learning new concepts
* DSA problem solving
* Documentation writing
* Academic support

### Why?

Sonnet delivers the best balance between speed and reasoning.

---

## 🚀 When to Use Opus

Use Opus for:

* Complex project architecture
* Deep research
* Advanced system design
* Technical strategy
* Long-form analysis

### Why?

Opus provides the strongest reasoning capabilities.

# 📊 My Personalized Claude Workflow

| Task                | Best Model | Best Effort     | Reason                           |

| Coding & Debugging  | Sonnet     | Standard / High | Accurate coding support          |

| Brainstorming       | Haiku      | Low / Standard  | Quick idea generation            |

---

# ❌ Biggest Mistakes To Avoid

* Using Opus for every task
* Always selecting Low Effort
* Giving vague prompts
* Not providing enough context
* Expecting perfect answers without iteration
* Skipping prompt refinement
